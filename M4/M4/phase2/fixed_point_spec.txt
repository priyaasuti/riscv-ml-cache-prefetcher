--- INPUT ENCODING (M3 trace buffer -> MLP input) ---------------
  CRITICAL — this changed from the old spec. Read carefully.

  Step 1: raw_delta_bytes = current_addr - prev_addr
  Step 2: int8_input = floor(raw_delta_bytes / 4)
           In Verilog: int8_input = $signed(raw_delta[31:0]) >>> 2

    delta =  0 bytes  -> int8 =  0
